# Open Source AI Agents for GitHub

> 5 autonomous GitHub Actions agents powered by OpenAI GPT-4o-mini to streamline open-source project management: issue triage, PR review, documentation sync, CI failure debugging, and multi-language community translation.

*Sistema de automatización de 5 agentes de GitHub Actions impulsados por OpenAI GPT-4o-mini para optimizar la gestión de proyectos de código abierto (open-source): triaje de issues, revisión de PRs, sincronización de documentación y lanzamientos, diagnóstico de fallos de CI y traducción comunitaria multilingüe.*

---

## 🤖 The 5 Agents

| Agent | Workflow | Script | Trigger | Capabilities |
|-------|----------|--------|---------|--------------|
| **1. Issue Triage** | `.github/workflows/issue-triage.yml` | `scripts/issue_triage.py` | `issues: opened` | Categorise labels (`bug`, `enhancement`, `documentation`, `question`), detect duplicate issues via cosine embeddings similarity, answer questions with FAQ links |
| **2. PR Reviewer** | `.github/workflows/pr-reviewer.yml` | `scripts/pr_reviewer.py` | `pull_request: opened, synchronize` | Analyse unified diff for bugs, security holes, style violations, performance issues; post structured review comment; warn on missing tests |
| **3. Docs & Release Notes** | `.github/workflows/docs-release.yml` | `scripts/docs_release.py` | `push: main`, `release: published` | Detect documentation drift from commits; generate structured markdown changelogs from merged PRs, update `CHANGELOG.md`, update GitHub release body |
| **4. CI Debugger** | `.github/workflows/ci-debug.yml` | `scripts/ci_debug.py` | `workflow_run: completed (failure)` | Fetch failed step logs from GitHub Actions run zip, diagnose root cause via GPT, post comment on PR or create tracking issue with actionable fix |
| **5. Community & Translation** | `.github/workflows/community-translate.yml` | `scripts/community_translate.py` | `issues: labeled ('translate')`, `schedule (weekly)`, `pull_request: opened` | Translate docs to 5 languages (`id`, `zh`, `ja`, `es`, `ar`), welcome first-time contributors on their first PR |

## 🚀 Setup Instructions / Instrucciones de Configuración

### 1. Store GitHub Repo Secret

1. Open your repository on GitHub.
2. Go to **Settings** > **Secrets and variables** > **Actions**.
3. Click **New repository secret**.
4. Name: `OPENAI_API_KEY`
5. Value: Your OpenAI API key starting with `sk-...`
6. Click **Add secret**.

> **Note:** `GITHUB_TOKEN` is automatically created and injected by GitHub Actions for every run. You do not need to add it manually.

### 2. Enable Workflow Permissions

By default, GitHub Actions tokens have read-only permissions in new repositories. Enable write access:

1. Go to **Settings** > **Actions** > **General**.
2. Scroll to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Check **Allow GitHub Actions to create and approve pull requests**.
5. Click **Save**.

### 3. Local Testing

To test scripts locally before pushing:

```bash
# Clone the repository
git clone https://github.com/your-username/opensource-agents.git
cd opensource-agents

# Set up virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env
# Edit .env with your actual OPENAI_API_KEY and GITHUB_TOKEN
```

Run a syntax check across all scripts:

```bash
python -m py_compile scripts/*.py
```

## ⚙️ Configuration & Customization

- **Model**: All scripts use `gpt-4o-mini` for fast response times and low cost. You can change `model="gpt-4o-mini"` to `gpt-4o` in `scripts/*.py` if needed.
- **Prompts**: Edit prompts in `.github/prompts/` to fit your project's coding standards, tone of voice, or specific issue labels.
- **Duplicate Threshold**: In `scripts/issue_triage.py`, adjust `DUPLICATE_THRESHOLD = 0.90` (0.0 to 1.0) to control how aggressively similar issues are flagged.
- **Target Languages**: In `scripts/community_translate.py`, modify `TARGET_LANGUAGES` to add or remove language codes.
